# SKRIPTIMINE koos GitHowTo-ga

Selles repositooriumis õpipis Bash skriptimist GitHowTO abil


### Projaktis siiamaani õpitu

- Branchide mergimine
- Branchide tegemin
- Branchide vahel liikumine
- Git push
- Git push tagasivõtmine
- Git commit tagasivõtmine


### Näited Git käskudest

'''bash
git switch
'''

'''bash
git push -u
'''

'''bash
git merge
'''

### Inline koodi näide

'''bash
<html>
  <head>
    <h1> teksti näidend </h1>
  </head>
</html>>
'''

## Git-i põhitöövoog

Git-i töövoo näide:

'''bash
git status
git add .
git commit -m "Kirjeldus muudatustest"
git push -uf "repo" "branch"
'''
